# RRU Student Traveler

**Welcome, Hitchhiker. Don't panic:** your Guide knows the way, and this traveler keeps your record.

This repo is your **traveler** for Runtime Republic University (RRU).

On a shop floor, a traveler is the work order that moves with a part. It lists every
operation and collects an inspection stamp at each station. Your traveler does the same
for your learning: every lesson you finish gets a stamp, with proof.

## How to start (Station 0)

1. Click **Use this template** → **Create a new repository**.
2. Owner: **your own GitHub account**. Name: `rru-traveler`. Visibility: **Private**.
3. Fill in `profile.md`.
4. Create a Claude Project for your track and connect this repo to it
   (see the course setup guide).
5. Take the placement test in your Project. Record the result in `placement/RESULT.md`.

## What's in here

| Folder / file | Purpose |
|---|---|
| `profile.md` | Who you are, your levels and your path |
| `STAMP-FORMAT.md` | The exact format for every stamp |
| `logs/` | One log per track: Claude AI, GitHub, Discord |
| `evidence/` | Screenshots, links and files that prove your work |
| `a3/` | One-page A3 reports, one per phase |
| `placement/RESULT.md` | Your placement test result |

## The one rule

A stamp without evidence is not a stamp. Record gaps and rework honestly.
A traveler that hides rework isn't worth the paper.
